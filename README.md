# Portofolio Novi Ardianto — versi publik hanya-baca

Website portofolio responsif berdasarkan CV Novi Ardianto.

## Cara menjalankan
1. Ekstrak file ZIP.
2. Buka folder `portfolio_novi_ardianto`.
3. Buka `index.html` menggunakan browser.

Tidak memerlukan instalasi Node.js atau server. Font menggunakan Google Fonts sehingga perlu koneksi internet untuk memuat font; website tetap dapat dibuka tanpa font tersebut.

## Privasi perubahan foto
- Pengunjung hanya dapat melihat isi portofolio. Tidak ada tombol unggah/hapus foto dan tidak ada penyimpanan foto melalui browser pengunjung.
- Untuk mengganti foto profil atau menambahkan foto sertifikat, pemilik harus mengedit file `index.html` (dan menambahkan file gambar ke folder proyek), lalu mengunggah/menerbitkan ulang website.
- Versi ini belum berisi foto pribadi atau foto sertifikat asli karena gambar tersebut belum disertakan pada saat pembuatan. Bagian foto masih berupa placeholder.

## Kustomisasi
- Edit nama, ringkasan, pengalaman, pendidikan, keahlian, dan kontak di `index.html`.
- Warna utama dapat diubah melalui variabel CSS di bagian `:root`.
- Email dan nomor telepon menggunakan tautan `mailto:` dan `tel:`.


## CV
File `CV_Novi_Ardianto.pdf` disertakan di folder ini dan dapat diunduh pengunjung melalui tombol **Unduh CV Saya (PDF)** pada kartu profil. Jangan memindahkan file PDF terpisah dari `index.html` saat mengunggah website.

## Foto profil dan sertifikat
Foto ditampilkan secara statis; pengunjung tidak mendapatkan tombol untuk mengganti atau menghapus foto. Untuk mengganti foto, pemilik perlu memperbarui aset HTML website lalu menerbitkan ulang.
